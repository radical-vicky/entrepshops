    How this works

    1. Create a source below for each Shopify store you want to import from.
    2. Click Preview on a source to see what it would import — nothing is saved.
    3. Click Run this import from the preview page, or run python manage.py import_supplier "<name>" from a terminal.
    4. Imported products land in Products, mixed with your existing ones. They are normal products — you can edit, price, and feature them just like any other.
